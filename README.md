# Пошук фільмів

Домашнє завдання №3 GoIT: пошук фільмів у TMDB на React 19, TypeScript та Vite.

[Робоча сторінка на Vercel](https://03-react-movies-ho-me2.vercel.app)

## Можливості

Пошук за назвою, галерея постерів і модальне вікно з описом, датою виходу та рейтингом. Передбачено індикатор завантаження, повідомлення про помилки й порожні результати, а також локальну заглушку для відсутніх зображень. Модальне вікно закривається кнопкою, клавішею Escape або кліком на фон; прокручування сторінки на цей час заблоковано.

## Локальний запуск

Потрібна Node.js `^20.19.0` або `>=22.12.0`.

```bash
npm ci
cp .env.example .env
```

У `.env` замініть приклад власним **TMDB API Read Access Token**:

```dotenv
VITE_TMDB_TOKEN=your_tmdb_bearer_token_here
```

Токен можна отримати в [налаштуваннях API TMDB](https://www.themoviedb.org/settings/api). Після цього запустіть:

```bash
npm run dev
```

Не комітьте `.env`: він уже доданий у `.gitignore`. Змінні `VITE_*` потрапляють у браузерну збірку, тому такий токен не є серверним секретом. Не використовуйте тут паролі або привілейовані серверні ключі.

## Структура

- `App` керує результатами, станами запиту й вибраним фільмом; скасовує застарілі запити.
- `SearchBar` збирає запит через React Form Actions і передає його батьківському компоненту.
- `MovieGrid`, `Loader`, `ErrorMessage` відповідають за відображення даних та станів.
- `MovieModal` використовує `createPortal` і прибирає глобальні обробники після закриття.
- `src/services/movieService.ts` містить типізований Axios-запит із Bearer-авторизацією.
- `src/types/movie.ts` містить спільний інтерфейс фільму.

Стилізація — CSS Modules із [навчального репозиторію](https://github.com/goitacademy/react-movies-styles), глобальна нормалізація — `modern-normalize`.

## Перевірки

```bash
npm run build
npm run lint
npm run format:check
npm test
```

Vitest і Testing Library перевіряють форму, життєвий цикл пошуку, застарілі відповіді, помилки, модальне вікно та HTTP-сервіс. У тестах API замінено контрольованими імітаціями; вони не потребують токена й не доводять доступність реального TMDB.

## Публікація на Vercel

1. Завантажте проєкт у репозиторій `03-react-movies` на GitHub.
2. Імпортуйте репозиторій у Vercel із пресетом **Vite**, командою збірки `npm run build` і директорією результату `dist`.
3. Додайте `VITE_TMDB_TOKEN` у **Settings → Environment Variables** для production до збірки. Якщо змінну додано пізніше, виконайте повторний деплой.
4. На публічній сторінці перевірте реальний пошук, порожній запит, відсутні результати та всі способи закриття модального вікна.
5. У LMS подайте посилання на GitHub-репозиторій і робочу сторінку Vercel.

Для локальної перевірки продакшен-збірки використовуйте `npm run preview` після `npm run build`.
